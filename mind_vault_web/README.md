# Mind Vault Web

Mind Vault 的 React Web 客户端，使用 Vite、TypeScript、TanStack Query、Zustand、Tailwind CSS 和 React Router 构建。

## Requirements

- Node.js `>=22.12`
- pnpm `10.33.0`

## Commands

```bash
pnpm install
pnpm dev
pnpm typecheck
pnpm test --run
pnpm build
pnpm lint
```

Copy `.env.example` to `.env.local` before connecting to the API.
