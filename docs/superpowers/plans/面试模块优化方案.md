## 一、背景与目标

### 1.1 现状

面试训练模块当前已形成一条完整闭环：**配置训练 → AI 出题 → 作答提交 → 评估反馈 → 薄弱点复习**，前后端代码均已就绪：

- 前端 5 个页面 + 面试特性模块（`interview-schema` 表单校验、`session-state` 流式状态机、`review-items` 过滤）。
- 后端 6 组接口：会话创建（含流式）、会话列表/详情、回答提交（含流式）、结束训练、复习项列表/详情/重答/状态更新。
- 出题与评估由 `InterviewAgentService` 驱动，采用 SSE `stage / result / done / error` 协议。

### 1.2 目标

按用户提出的四个维度，对面试模块做一次系统性优化：

1. **功能完整性**：补齐或修正闭环中缺失/失真的环节。
2. **UI 设计**：修正布局与控件缺陷，统一视觉层级与设计语言。
3. **交互体验**：减少无反馈的等待、补齐操作结果反馈、提升响应感。
4. **兼容性**：桌面三档断点与主流浏览器/设备可用。

### 1.3 非目标（本期不做）

| 项 | 原因 |
|---|---|
| 面试安排（日程/计划/提醒）与简历展示 | 当前代码中不存在，属另一产品形态；**已确认本期不新增**（见第六章），本期仅优化现有闭环 |
| 引入真实语音面试 / 音视频 | 与现有文本问答链路无关，属新产品形态 |
| 多端（小程序）面试页 | 现有面试页为 Web 端，另行评估 |
| 评估模型/评分口径算法重写 | 评分 prompt 口径已冻结（不接收用户自定义提示词），本期不改口径 |
| 团队协作 / 面试官席位 | 面试数据按 `ownerId` 严格隔离，不做共享 |

## 四、优化方案

### 4.1 功能完整性

1. **修复多题评价失真（F1）**：反馈页聚合同一会话全部 `turns[].evaluation`，对 `accuracy/depth/structure/clarity` 分别求平均作为综合与维度得分；同时新增**逐题得分列表**（题目 / 得分 / 优缺点要点）。纯前端改动。
2. **修复平均得分（F2）**：由会话 `turns` 的评估分数聚合计算（前端），避免为统计新增后端接口。
3. **修复复习「全部」筛选（F3）**：后端 `listReviewItems` 支持 `status=ALL` 并走**后端分页**（已确认允许改后端，采用此方案）；前端移除「两次请求拼接」逻辑，改为单次请求。
4. **修正首页最近训练（F4）**：改为展示「最近 N 条会话（含进行中）」，空态仅在确实无任何会话时出现。
5. **复习重答结果反馈（F5）**：提交后展示本次得分、是否达标自动完成、以及 `attempts` 历史（接口已返回）。
6. **会话内回答记录（U5）**：会话页增加「已答题」折叠区 / 侧栏，展示题干、我的回答与上题得分，可回看但不可改（重答走复习链路，符合既有工程约定）。
7. **跳过语义（U6）**：抽为独立的 skip 动作（携带标记位或专用接口），不将「跳过」文本当作答案落库。

### 4.2 UI 设计

1. **修复筛选控件（U1）**：为文字型分段控件新增样式变体（如 `.segmented-control--text`，`width: auto; padding: 0 12px`），或改用按钮组；图标型保持原样，避免回归影响资料库页。
2. **修复表单对齐（U2）**：表单行 `align-self/align-items: start`，使同排字段顶部对齐；textarea 与 input 基线一致。
3. **新建训练表单重排（UI2/UI3）**：合理列宽比例、主按钮不再整行铺满（桌面端右对齐或定宽），为每个主题补充一句说明文案，为强度补充「快速：每题独立出新题 / 深度：基于本题追问」提示。
4. **首页层级与留白（UI1）**：区分统计卡/主行动卡/列表面板的视觉权重，压缩底部空白，统一卡片间距与标题字号梯度。
5. **危险/不可逆操作确认（UI4）**：标记已掌握改为轻提示 + 撤销（已确认允许引入 toast 类依赖）。
6. **评分口径透明（UI5）**：将「证据引用」从评分维度中拆出，作为独立指标展示（如「引用资料 N 条」），不与四维评分并列。
7. **清理冗余节点（UI6）**。

### 4.3 交互体验

1. **统一等待反馈（U3/U4）**：新建训练复用既有三重反馈范式（转圈 + 阶段文案 + 已等待计时）；会话页区分「本题计时」与「总用时」，并在评估阶段给出阶段文案。
2. **统一错误态（U7）**：全部替换为 `ErrorState`（含重试），文案中文化，与检索页一致。
3. **操作结果反馈**：提交、结束、标记掌握等动作补齐成功/失败反馈；SSE 中断时保留草稿并提供重试（现有能力保留并统一展示）。
4. **减少步骤**：首页「继续训练」直达当前题；复习项从反馈页一键跳转已具备，补齐返回路径与面包屑一致性。

### 4.4 性能与可访问性

1. **路由懒加载（A1）**：面试 5 个页面改 `lazy` + `Suspense`，与检索页一致，降低主包体积。
2. **可访问性（A2）**：为 `progress`、计时器、筛选控件补 `aria-label` / `aria-live`；保证每页唯一 `h1` 与标题层级；键盘可达性与焦点态复用检索阶段新增的 `:focus-visible` 全局焦点环。
3. **列表分页（A4）**：面试会话列表后端支持分页参数（已确认允许改后端）。

### 4.5 兼容性

- **浏览器矩阵**：Chrome、Safari、Firefox、Edge 最新稳定版。
- **设备/断点**：1440（桌面）、1024（平板）、390（移动）三档走查；覆盖触控与键盘两种输入。
- **重点核查**：`:focus-visible`、`dvh`、`sticky`、`<progress>`、`backdrop-filter` 在 Safari 的降级表现。
