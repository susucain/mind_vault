# 首页与会话管理设计

## 目标

将首页从服务状态页调整为个人知识工作台，并提供统一的会话管理能力。用户能够继续最近的资料问答或面试训练，也能够从首页发起一个面向全部资料集的新资料问答会话。

## 范围

- 首页工作台布局与输入提问入口。
- 资料问答与面试训练的混合最近会话列表。
- 独立会话管理页。
- 聊天页恢复、切换资料问答会话。
- 面试页恢复指定训练会话。
- 资料问答会话的活跃时间与标题维护。

不在本次范围内：

- 删除、重命名、归档会话。
- 分页加载会话。
- 真实模型 token 流。

## 首页

首页按以下顺序展示：

1. 品牌与问候。
2. 资料问答输入框。
3. 今天继续：最近资料问答和最近面试训练。
4. 最近会话：资料问答、面试训练混合排序，最多 3 条。
5. 最近资料。
6. 待复习。

首页不展示服务状态。网络或数据加载失败使用现有 `app-state` 组件表示。

### 首页提问

用户从首页提交问题时：

1. 读取用户全部可用资料集。
2. 使用全部资料集 ID 创建资料问答会话。
3. 将新会话 ID 和待发送问题传给聊天页。
4. 聊天页自动发送该问题。

新会话的初始标题由问题前 28 个字符生成；空白清理后不足 28 个字符时使用完整问题。

如果用户没有可用资料集，输入框不可提交，页面提示先到知识库创建资料集。

## 会话模型

前端新增统一的 `SessionListItem` 映射模型：

```ts
type SessionKind = 'chat' | 'interview';

interface SessionListItem {
  id: string;
  kind: SessionKind;
  title: string;
  subtitle: string;
  updatedAt: string;
  status?: 'IN_PROGRESS' | 'COMPLETED' | 'ABORTED' | 'FAILED';
}
```

资料问答映射：

- `id`: conversation ID。
- `title`: 会话标题。
- `subtitle`: 关联资料集数量。
- `status`: 无需展示时省略。

面试训练映射：

- `id`: interview session ID。
- `title`: 训练模式和当前题目序号。
- `subtitle`: 关联资料集名称。
- `status`: `IN_PROGRESS` 或 `COMPLETED`。

小程序并行获取 `GET /conversations` 与 `GET /interview/sessions`，映射后按 `updatedAt DESC` 合并排序。首页取前 3 条，独立会话页显示全部。

## 会话入口与恢复

### 资料问答

- 从首页“资料问答”进入时，加载最近资料问答会话；没有历史才创建新会话。
- 首页的输入提问始终创建新会话。
- 聊天页接收 `conversationId` 时加载指定历史消息。
- 聊天页顶部会话切换器只列出资料问答会话。
- 聊天页“新会话”创建空白资料问答会话。

### 面试训练

- 新增 `GET /interview/sessions`，按 `updatedAt DESC` 返回当前用户训练会话。
- 面试页接收 `sessionId` 时调用现有 `GET /interview/sessions/:id` 恢复训练、轮次和当前问题。
- 点击混合会话列表中的面试项，跳转面试页并传入 `sessionId`。

## 后端一致性

`ConversationEntity.updatedAt` 必须在每轮资料问答完成、失败或取消后更新。正常消息写入后保存会话实体，使资料问答可按真实活跃时间排序。

新会话的首条用户消息写入后，若会话标题仍为默认值 `资料问答`，更新标题为问题摘要。

面试训练已经在创建、提交回答和结束训练时保存 session，`updatedAt` 可作为真实活跃时间。

## 页面设计

### 独立会话页

- 路径：`pages/sessions/sessions`。
- 筛选：全部、资料问答、面试训练。
- 会话项为单层列表，不嵌套卡片。
- 显示类型图标、标题、副标题、相对时间和训练状态。
- 空状态提供返回首页开始提问或开始训练的入口。

### 聊天页

- 顶部显示当前会话标题。
- 会话切换按钮打开资料问答会话选择器。
- 切换期间不允许发送消息。
- 正在生成时禁止切换会话；先停止生成后才能切换。

## 验收

- 首页输入问题会创建关联全部资料集的新会话并自动发送。
- 进入资料问答默认恢复最近资料问答会话。
- 无历史会话时才创建空白会话。
- 最近会话混合展示资料问答与面试训练，并按真实活跃时间排序。
- 面试训练会话能恢复当前题目、进度和历史轮次。
- 资料问答会话切换器不会显示面试训练会话。
- 首页不再显示服务状态。
