# 知识库上传与文档状态设计

## 方向

采用 Organic 方向，延续知识库已有的暖纸、深绿和人文衬线标题风格。差异化动作是把状态从彩色胶囊收敛为轻量的线性图标加文案，让表格更像可扫描的工作台；上传流程则用一个聚焦的居中弹窗承载文件选择，把持续变化的状态留在主表格中。

## 目标

- 状态列使用图标加文案，不显示文字背景色。
- 覆盖等待处理、上传中、处理中、可问答、处理失败和已归档。
- 点击「上传」打开居中弹窗。
- 弹窗负责资料集选择、拖拽/选择文件和文件校验。
- 文件入队后关闭弹窗，页面切换到「全部文件」。
- 上传文件状态在主页面表格中显示，不在弹窗中显示上传队列。
- 关闭弹窗不取消上传。

## 交互

1. 用户点击知识库页右上角「上传」。
2. 页面打开居中「上传文件」弹窗，背景内容保持可见但不可操作。
3. 用户选择目标资料集，或在有需要时点击「新建」创建资料集。
4. 用户拖放文件或点击「选择文件」选择一个或多个文件。
5. 文件通过现有上传队列入队后，弹窗立即关闭。
6. 页面筛选复位为「全部文件」，搜索条件清空，文档查询刷新。
7. 主表格出现新文档行，状态从「等待处理」或「上传中」推进到「处理中」「可问答」或「处理失败」。
8. 用户可以关闭弹窗而不影响已经开始的上传。

没有资料集时，弹窗显示创建资料集引导，文件选择不可用。格式或大小校验失败的文件仍作为失败状态保留在主表格中，并展示可重试入口。

## 组件与数据流

### `LibraryPage`

- 管理 `uploadOpen`、资料集筛选、搜索条件和分页。
- 上传成功入队后将资料集筛选切换为全部文件，清空搜索和分页。
- 继续通过 React Query 查询服务端文档。
- 将上传 store 中的本地临时项映射成表格行，与服务端文档按 `documentId` 合并，避免重复。

### `UploadPanel`

- 保留资料集下拉、创建资料集入口、拖拽区、文件选择和现有校验。
- 作为 `Dialog` 的内容渲染。
- 不再渲染 `UploadQueue`。
- 文件入队后通过回调通知父页面关闭弹窗并复位筛选。

### `DocumentStatusIndicator`

- 接收 `Document` 或上传队列状态。
- 统一映射图标、文案、语义颜色和无背景布局。
- 状态映射：
  - `pending` / `queued`: Clock3 + 等待处理
  - `uploading`: Upload + 上传中
  - `processing`: LoaderCircle + 处理中
  - `ready`: CircleCheck + 可问答
  - `failed`: TriangleAlert + 处理失败
  - `archived`: Archive + 已归档
  - `deleted`: CircleX + 已删除

### `useUploadQueue`

复用现有上传、轮询、取消、重试和停止跟踪逻辑。上传状态变化继续写入 Zustand store；React Query 失效逻辑继续触发服务端文档刷新。

## 样式

- 状态指示器为 `inline-flex`，图标固定 16px，文案与图标间距 6px。
- 状态指示器不设置 `background`、胶囊圆角或内边距。
- 保留语义颜色：成功深绿、处理中/等待琥珀、失败砖红、归档灰绿。
- 上传弹窗宽度控制在 560px 以内，顶部标题区、资料集选择区、主拖拽区和底部说明分层。
- 桌面端弹窗居中；移动端使用接近底部的全宽弹窗布局，避免内容被挤压。
- 上传按钮仍使用现有 `Upload` 图标和主色按钮样式。

## 错误处理

- 无资料集：显示创建资料集引导。
- 不支持的扩展名或超过 100MB：上传项状态为失败，保留错误原因和重试入口。
- 上传接口失败：主表格状态为失败，支持再次重试。
- 关闭弹窗：只改变弹窗可见性，不取消上传或清除上传 store。
- 服务端文档尚未返回时：使用本地临时行展示文件名和上传状态；服务端行出现后按 `documentId` 合并。

## 验证

- Vitest：验证状态到图标/文案的映射，上传后筛选复位，弹窗不渲染上传队列，失败行可重试。
- TypeScript：运行 `pnpm typecheck`。
- ESLint：运行 `pnpm lint`。
- 构建：运行 `pnpm build`。
- 浏览器检查：桌面和移动视口检查状态列、弹窗层级、拖拽区、溢出和状态更新期间的布局稳定性。

## 范围

本次不修改后端上传接口、文档状态协议、资料集接口和其他页面的上传入口。现有公共 `StatusBadge` 保留给其他场景使用，知识库表格状态改用新的状态指示器。
